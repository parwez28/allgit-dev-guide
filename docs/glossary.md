# Glossary: GitHub Terms Every Buyer Should Know

**Account age** — How long ago the GitHub account was created. Older accounts
with continuous activity are generally more trusted, by both people and
automated systems.

**Arctic Code Vault** — A 2020 GitHub initiative that archived a snapshot of
public open-source code in the Arctic for long-term preservation.
Contributors whose code was included received a badge that can never be
earned again.

**Badge** — An official GitHub achievement displayed on a profile. Some are
earned through activity (Pull Shark, Starstruck); others are time-locked
(Arctic Code Vault, Mars 2020).

**Contribution graph** — The grid of green squares on a GitHub profile
showing commit activity over time. A long, consistent graph signals
sustained development work.

**Followers** — Other GitHub users who follow a profile. A real follower
base suggests the account's work is watched and valued by the community.

**Fresh account** — An account 0–6 months old with little to no history.
Useful as a secondary, bot, or clean-slate identity.

**Full ownership transfer** — The process of making a purchased account
exclusively yours: changing the password, replacing the email, enabling
2FA, generating new recovery codes, and clearing old sessions and keys.

**Galaxy Brain** — Badge earned when your answers in GitHub Discussions are
marked as accepted. Signals trusted community knowledge.

**Legend tier** — Accounts 5+ years old with the deepest history and rarest
badges. The top tier of aged-account inventory.

**Mars 2020 Contributor** — Badge for contributors whose code powered the
Mars 2020 helicopter mission software. Frozen in time; impossible to earn
now.

**Merged pull request** — A proposed code change that a repository
maintainer reviewed and accepted. A history of merged PRs is one of the
strongest signals of real open-source participation.

**Pair Extraordinaire** — Badge for co-authored commits made through pair
programming. Signals collaborative experience.

**Pull Shark** — Badge earned through merged pull requests, with tiers
scaling to dozens of accepted PRs. High tiers indicate a serious
contributor.

**Replacement warranty** — The seller's guarantee: if the account develops
access issues within the warranty period, it's replaced with an equivalent
or better profile at no cost.

**Starstruck** — Badge awarded as repositories you created earn stars (tiers
at 16, 128, 512, and 4096 stars). Direct social proof of valued work.

**Two-factor authentication (2FA)** — A security layer requiring a second
verification step beyond the password. Essential to enable immediately after
receiving any transferred account.

**Veteran tier** — Accounts 3–4 years old with deep history and rare badges.
Favored for client-facing and high-stakes use.
