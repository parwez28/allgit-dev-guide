# GitHub Badges: The Complete Guide

GitHub badges are official achievements displayed on a developer's profile.
Each badge tells a verifiable story about what the account holder has done —
and, crucially, *when* they did it. Some badges can be earned in a matter of
weeks. Others are frozen in time and can never be earned again, which is what
makes them so valuable on aged accounts.

---

## Extremely rare: badges frozen in time

### Arctic Code Vault Contributor

In 2020, GitHub archived a snapshot of public open-source code in an Arctic
vault designed to preserve it for a thousand years. Developers whose code was
included received the Arctic Code Vault Contributor badge.

**Why it matters:** This badge can never be earned again. It is proof that
the account existed and was contributing to open source before mid-2020. On a
profile, it functions as an unforgeable timestamp of seniority.

### Mars 2020 Contributor

GitHub awarded this badge to contributors whose code helped power the
software behind NASA's Mars 2020 helicopter mission.

**Why it matters:** Like the Arctic badge, it is frozen in time — only code
merged during that specific mission window qualified. New accounts can never
obtain it. It signals both longevity and participation in a genuinely historic
engineering effort.

---

## Earned through contribution

### Pull Shark

Awarded for getting pull requests merged into repositories. It has multiple
tiers, with the highest tiers requiring dozens of merged PRs.

**Why it matters:** A high-tier Pull Shark badge on an aged account signals
a genuine open-source contributor — someone whose code was reviewed and
accepted by maintainers repeatedly — not a tourist. It's one of the most
respected earned badges because it reflects real collaborative work.

### Pair Extraordinaire

Awarded for co-authored commits created through pair programming.

**Why it matters:** It demonstrates collaborative experience, something
employers and clients actively look for. Earning it requires real partnered
work, so it can't be faked with solo commits.

### Galaxy Brain

Earned when your answers in GitHub Discussions are marked as the accepted
answer.

**Why it matters:** It marks the account holder as someone the developer
community trusts for knowledge. Achieving it takes sustained, helpful
participation — answering real questions well enough that others mark your
responses as correct.

### Starstruck

Awarded when repositories you created earn stars from other developers. It
has tiers at 16, 128, 512, and 4096 stars.

**Why it matters:** Stars are other developers voting with their attention.
Starstruck tiers are direct social proof that the community values your work.
Higher tiers indicate projects with genuine adoption.

## Why badges matter on aged accounts

Anyone can *claim* seniority on a résumé. A profile carrying the Arctic Code
Vault or Mars 2020 badge *proves* presence during historic moments in open
source — no claim required. That's why platforms like allgit.dev curate their
veteran and legend tier accounts specifically around badge portfolios: each
listing documents exactly which badges are on the profile, so buyers know
what they're getting before they pay.

When evaluating an aged account, look at the badge set as a whole:

- **Time-locked badges** (Arctic, Mars 2020) prove *when* the account was
active.
- **Contribution badges** (Pull Shark, Pair Extraordinaire, Galaxy Brain)
prove *how* the account was used.
- **Social proof badges** (Starstruck) prove *what others thought* of the
work.

Together, they form a credibility fingerprint that would take years to build
from scratch — and in the case of the frozen badges, couldn't be built at
all.
